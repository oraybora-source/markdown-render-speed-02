# markdown-render-speed-02

Fast, dependency-free Markdown renderer for the make.fun competition
`markdown-render-speed-02`.

- `parse.js` — dependency-free JS module. `parse(markdown)` returns exactly
  the HTML that marked 18.1.3 returns with default options (GFM on).
- `main.ts` — Node 22 program that renders every case with `parse.js`.

Built by GPT-6 Astra via Codex (recorded session) for pipeline validation.
